## 虚拟主机、VPS、独立服务器，先分清你要买的是哪种

三者差别在于资源隔离程度。虚拟主机也叫共享主机，是把一台物理服务器分隔成若干个主机单独出售，CPU、内存这些资源大家共享，大多数情况下 IP 也是共享的。它的用途基本只有一个：托管网站。建个博客或者企业官网，把程序放上去，别人就能访问；代价是性能有限，撑不起大流量。

VPS 则把 CPU、内存、存储完全分隔开，每台都有独立 IP，用起来相当于一台独立服务器。除了放网站，你还可以自己装环境、跑程序。价格比虚拟主机贵一些，自由度完全不在一个级别。

判断方法很直接：只用 WordPress、Discuz! 这类现成程序建站，虚拟主机够用；要自己折腾环境、需要独立 IP，直接看 VPS。真到了买 VPS 的阶段，可以拿这个价格做参照：GoDaddy 的入门 VPS（1 核 2GB、40GB NVMe 存储）前三年 ¥65/月。

另外注意操作系统。Linux 主机托管 PHP、Python 程序，Windows 主机托管 ASP.NET 程序，市面上大多数商家只提供 Linux 主机。网站如果是 ASP.NET 写的，下单前先确认有没有 Windows 方案，免得买完发现装不上。

## 不用备案是真的，但速度取决于机房和线路

国内主机托管网站需要备案，海外主机不用，买完直接解析域名就能上线。这也是香港和美国机房用得多的原因——距离近，国内访问速度相对有保障。

同一间机房，线路不同，体验能差出一截。CN2 GIA 是电信的高端出口，延迟低、丢包少，晚高峰也不容易掉速。走这条线路的商家不少：bluehost 的香港机房每月 19 元起，恒创主机香港机房每月 88 元，搬瓦工 CN2 GIA 线路 50 美元/季度、最高支持 10Gbps 带宽，Hostdare 年付 50 美元。

## 下单前，把这五件事过一遍

1. **程序语言定系统**：PHP、Python 网站选 Linux 主机，ASP.NET 选 Windows 主机，而多数商家只做 Linux。
2. **支付方式**：国内用户优先确认支不支持支付宝。Vultr、Hostwinds、搬瓦工都支持；Hostwinds 每月 4.99 美元起，1000Mbps 带宽，后台可以免费换 IP。
3. **续费价**：把续费月价找出来，按两三年算总账，别只看首年数字。
4. **退款政策**：GoDaddy 有 30 天退款保证，InterServer 支持 30 天无条件退款。拿不准的方案，优先选带退款期的试水。

## 常见问题

### 海外虚拟主机需要备案吗？

不需要。备案只针对用国内主机托管网站的情况，海外主机购买后直接解析域名就能上线，常见选择是香港和美国机房。

### 虚拟主机和 VPS 到底买哪个？

只跑 WordPress、Discuz! 这类现成程序，虚拟主机够用也更便宜；要自己装环境、跑应用、需要独立 IP，买 VPS。

### 为什么第二年续费贵这么多？

首年折扣是拉新手段，续费按原价执行。GoDaddy 经济版首年 ¥17/月、续费 ¥85/月就是典型例子，付款前把续费价确认一遍。

### 国内访问速度主要看什么？

机房位置加线路。CN2 GIA 延迟低、丢包少，DMIT 香港机房三网平均延迟 43ms 左右；预算有限时，至少选有亚洲带宽优化的商家。

### 做 SEO 站群要注意什么？

核心是独立 IP 数量和带宽。RackNerd 有专门的 SEO 多 IP 站群服务器，10Gbps 带宽，39 美元/月起，比逐台买 VPS 省心。
